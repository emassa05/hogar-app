# Requerimientos funcionales

## RF01. Gestión del hogar

El sistema deberá permitir crear, editar y abandonar un hogar, invitar o retirar integrantes y asignar permisos de administración. Un usuario podrá pertenecer a uno o más hogares.

## RF02. Gestión de integrantes

El sistema deberá permitir consultar y modificar el perfil doméstico de cada integrante, incluyendo nombre, disponibilidad, restricciones, preferencias y capacidad aproximada para asumir tareas.

## RF03. Gestión de tareas y responsabilidades

El sistema deberá permitir crear, editar, asignar, reasignar, eliminar y consultar tareas, indicando categoría, descripción, responsable, fecha, frecuencia, prioridad, duración estimada, esfuerzo y carga mental asociada.

Las tareas podrán ser individuales, compartidas, asignadas o estar disponibles para que algún integrante las tome.

## RF04. Gestión de rutinas

El sistema deberá permitir crear tareas recurrentes, definir sus días o intervalos, establecer una fecha de término y distribuirlas mediante asignación fija, rotativa o alternada entre los integrantes.

## RF05. Registro y seguimiento de tareas

El sistema deberá permitir marcar una tarea como pendiente, completada o atrasada, registrando quién realizó la acción y cuándo. También deberá permitir consultar el historial de cumplimiento.

## RF06. Visualización de la distribución de carga

El sistema deberá mostrar la distribución de la carga entre los integrantes considerando cantidad de tareas, duración, esfuerzo, frecuencia, prioridad y carga mental. Además, deberá permitir comparar periodos e identificar desequilibrios.

## RF07. Gestión de alertas y recordatorios

El sistema deberá generar recordatorios configurables para tareas próximas, pendientes, o prioritarias. Cada integrante podrá elegir los tipos de aviso y los momentos en que desea recibirlos.

## RF08. Sugerencias de redistribución

El sistema deberá detectar concentraciones de carga y sugerir reasignaciones considerando disponibilidad, restricciones, preferencias, historial y carga acumulada.

Cada sugerencia deberá presentar una justificación y requerir confirmación antes de modificar la asignación.


## RF09. Panel general del hogar

El sistema deberá proporcionar un panel personalizado que muestre las tareas del día, tareas atrasadas, próximas responsabilidades, alertas, carga de cada integrante y sugerencias de redistribución.

## RF10. Gestión de disponibilidad y restricciones

El sistema deberá permitir que cada integrante indique los días u horarios en los que puede asumir tareas y registre restricciones permanentes o temporales.

## RF11. Intercambio de tareas y solicitud de ayuda

El sistema deberá permitir que los integrantes soliciten un intercambio de tareas.

La reasignación deberá ser confirmada por los integrantes involucrados.

## RF12. Registro de tareas no planificadas

El sistema deberá permitir registrar tareas imprevistas una vez realizadas, para que sean consideradas en el cálculo de la carga real del hogar.

## RF13. Índice de carga doméstica

El sistema deberá calcular la carga individual y total del hogar durante un periodo determinado, considerando duración, esfuerzo, frecuencia, prioridad y carga mental de las tareas.

El sistema deberá mostrar de manera comprensible los factores utilizados para realizar el cálculo.

## RF14. Preferencias de asignación

El sistema deberá permitir que cada integrante indique sus tareas preferidas, aquellas que no puede realizar y las que requieren habilidades, condiciones o autorizaciones específicas.

## RF15. Comentarios y coordinación por tarea

El sistema deberá permitir agregar comentarios, instrucciones o información relevante a una tarea para facilitar su coordinación entre los integrantes.

## RF16. Historial y estadísticas

El sistema deberá permitir consultar la evolución de la distribución de carga por semana o mes, incluyendo tareas realizadas, atrasadas, reasignadas y asumidas de manera imprevista.

## RF17. Plantillas de organización

El sistema deberá ofrecer plantillas opcionales de tareas y rutinas para diferentes tipos de hogares y categorías.

## RF18. Configuración del modelo de equilibrio

El sistema deberá permitir que el hogar establezca la disponibilidad o capacidad esperada de cada integrante, para calcular una distribución equilibrada según sus circunstancias.

El equilibrio no deberá asumir necesariamente que todos los integrantes realizan la misma cantidad de tareas.
